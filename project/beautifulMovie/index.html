  • Pages

    메인

  • Docs

    프로젝트 기술서
  • 풀스크린 반응형 웹

    영화의 상징적인 이미지를 고려하여 너비 1600px까지 대형 스크린에 가득차는 반응형 웹으로 설계했습니다.

    상대적 폰트 단위(rem)를 적용했습니다.일반 : 62.5%, 1300px : 58%, 900px : clamp(54%,1vw,58%), 600px : 52%

  • 디자인

    주요 서비스를 소개하는 메인 비주얼 섹션의 배경에 페럴렉스 효과를 적용했습니다. 모바일과 태블릿에서 사용자 경험 및 호환성을 위해 일반 이미지를 표시합니다.

    각 섹션에 서로 다른 레이아웃을 적용하여 페이지 이탈률을 낮춥니다.

  • 효율성 및 유지보수

    SASS 전처리기 프로젝트를 위한 아키텍쳐를 활용하여 코드의 유지보수가 용이합니다.

    CSS를 주석과 공백을 생략한 압축(compressed) 방식으로 컴파일하여 용량을 줄였습니다.

    부트스트랩 프레임워크를 활용하여 크로스 브라우징과 레이아웃 수정에 용이합니다.

    HTML5 기반 video.js를 사용하여 호환성이 높고 플레이어 스타일링이 편리합니다.
